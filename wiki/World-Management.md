# 게임 월드 관리

## 등록과 저장

게임 월드는 `plugins/Quake/quake.db`의 `game_worlds` 테이블에 저장합니다. 월드 목록과 이동 메뉴에는 기본 오버월드와 정상 로드된 게임 월드가 표시됩니다. 게임 월드 삭제 메뉴와 자동 로테이션은 등록된 게임 월드를 대상으로 합니다.

- 블록·청크·기본 월드 스폰은 월드 폴더에 저장합니다.
- 팀별 스폰은 SQLite에 저장합니다.
- 백업할 때는 서버를 종료하고 DB 파일과 월드 폴더를 함께 복사합니다.
- 월드 파일이 없으면 경고를 남기고 로드를 건너뛰며 빈 월드를 자동 생성하지 않습니다.

기존 버전의 월드는 자동 등록되지 않습니다. 월드 폴더를 백업한 뒤 월드가 로드되지 않은 상태에서 `/quake world create <기존 월드 이름>`을 실행하면 기존 폴더를 등록합니다. 이 과정에서 게임 규칙·시간·스폰 위치를 초기화합니다.

삭제는 등록된 월드에만 허용됩니다. 파일 삭제가 실패하면 등록 해제 상태로 남으므로 로그를 확인하고 남은 폴더를 직접 정리해야 합니다.

## 월드 관리 정보

`game_worlds`에는 다음 정보를 저장합니다.

| 컬럼 | 내용 |
| --- | --- |
| `world_uuid` | 실제 Bukkit 월드 UUID. 중복 등록 불가 |
| `display_name` | 목록·메뉴 표시 이름. 기본값은 월드 이름 |
| `status` | `READY`, `MAINTENANCE`, `DISABLED` |
| `created_at` | 등록 시각(UTC ISO 8601) |
| `created_by` | 생성 명령 또는 Dialog를 실행한 플레이어 UUID |
| `rotation_order` | 준비 완료 전환 순번 |

신규 월드는 `MAINTENANCE` 상태로 생성됩니다. 기존 이름만 있는 테이블은 시작 시 자동 확장하며, 기존 월드의 UUID는 정상 로드 시 채웁니다. 알 수 없는 등록 시각·생성자는 `NULL`로 유지합니다. UUID가 다르면 목록에서 제외하고 경고합니다.

표시 이름을 SQL로 변경한 경우 서버를 재시작해야 반영됩니다. 상태와 순번은 명령어로 변경하세요.

## 월드별 인원

인원 설정은 명령어와 SQLite 제약으로 검증합니다. 최소 인원은 2명 또는 4명만 가능하며, 최대 인원은 2~16 사이의 짝수입니다. 기존 DB도 시작 시 기본값으로 확장하고, 기존 최소 인원이 4명을 초과하면 4명으로 조정합니다. 현재 로테이션 월드의 최소 인원을 충족해야 카운트다운에 진입하며, 게임 시작 시 최대 인원까지만 참여합니다.

## 월드 로테이션

양 팀 스폰이 설정되고 정상 로드된 `READY` 월드를 준비 완료 순서로 순환합니다.

1. 새로 `READY`가 된 월드는 대기 목록의 마지막에 추가됩니다.
2. 각 월드는 참가자를 최대 30초 동안 기다립니다.
3. 최소 인원이 충족되면 즉시 30초 게임 시작 카운트다운으로 전환합니다.
4. 인원이 부족한 채 30초가 지나면 참가 신청을 유지한 채 다음 월드로 이동합니다.
5. 준비된 월드가 없으면 게임을 시작하지 않고 30초마다 다시 확인합니다.

게임 시작 시 신청 순서대로 최대 인원까지 팀에 배정하고 스폰으로 이동합니다. 초과 인원은 다음 게임 대기열로 넘깁니다. 게임 종료·취소 후 다음 월드로 이동하며, 온라인 참가자는 게임 시작 전 위치로 돌아갑니다. 카운트다운 중 이탈하면 카운트다운을 초기화하고, 최소 인원 미달이면 해당 월드에서 다시 30초를 기다립니다.

## 월드 준비와 팀 스폰

맵 제작 후 각 팀의 시작 위치에서 스폰을 저장합니다. 좌표와 시선 방향(yaw/pitch)을 함께 저장합니다.

```text
/quake world spawn arena red
/quake world spawn arena blue
/quake world status arena ready
```

양 팀 스폰이 모두 있어야 `READY`로 전환할 수 있습니다. `READY`를 다시 실행해도 순서는 바뀌지 않습니다. `MAINTENANCE` 또는 `DISABLED`로 변경하면 이후 로테이션에서 제외되고, 다시 `READY`로 변경하면 대기 목록 끝에 추가됩니다. 이미 진행 중인 게임은 끝까지 진행합니다.

스폰 수정은 해당 월드 안에서 `MAINTENANCE` 상태일 때만 가능하며, 게임 중인 월드에서는 변경할 수 없습니다. 스폰은 `world_spawns` 테이블에 월드와 팀(RED/BLUE)별 x/y/z/yaw/pitch로 저장합니다. 스폰이 없는 기존 `READY` 월드는 로테이션에서 제외되므로 점검 상태로 전환한 뒤 설정해야 합니다.

DB의 순번과 스폰은 재시작 후에도 유지되며, 재시작 시 준비 완료 순서부터 새 로테이션을 시작합니다.
