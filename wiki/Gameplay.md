# 게임 플레이

## 참여

- 접속하면 메뉴 책을 받습니다.
- 책을 우클릭하면 Dialog 참여 메뉴가 열립니다.
- 일반 플레이어는 메뉴 책을 버릴 수 없습니다.
- 참여 취소 또는 접속 종료 시 카운트다운이 초기화됩니다. 남은 인원이 최소 인원 이상이면 처음부터 다시 시작합니다.

월드별 참가 인원과 로테이션 대기 시간은 보스바에 표시됩니다. 참가자가 최소 인원을 충족하면 30초 게임 시작 카운트다운을 진행합니다.

## 게임 진행

- 게임 시작 시 RED/BLUE 팀에 무작위로 균등 배정합니다. 최소 1:1을 유지하며 홀수 인원은 한 명 차이로 배정됩니다.
- 상대 팀의 머리 위 닉네임을 숨깁니다.
- 게임 참여자에게만 팀 색상과 팀별 정렬이 적용된 탭 목록을 표시합니다.
- 탭 목록에는 헤더·푸터와 플레이어별 처치 수가 표시되며, 푸터에는 팀별 총 처치 수가 실시간으로 표시됩니다.
- 종료·퇴장 시 닉네임 표시, 스코어보드, 탭 목록을 기존 상태로 복원합니다.
- 한 팀의 모든 플레이어가 나가면 게임을 취소하고 남은 인원은 다음 게임에 자동 참여합니다.

게임 시간 기본값은 180초이며, 관리자가 변경할 수 있습니다. 변경 사항은 다음 게임부터 적용되고 서버 재시작 후에도 유지됩니다.

## 사이드바

화면 오른쪽 사이드바에 서버 정보를 표시합니다. 내용은 1초마다, 점수는 득점 즉시 갱신됩니다.

- 로비: 접속 인원, 다음 맵(게임 중이면 진행 중인 맵), 참여 인원, 내 참여 상태(미참여·참여 대기·다음 게임 대기)
- 게임 참가자: 내 팀, 팀별 점수, 목표 점수, 남은 시간

제목과 맨 아래 주소 줄은 `plugins/Quake/config.yml`에서 MiniMessage 형식으로 바꿉니다. `sidebar.address`가 비어 있으면 주소 줄을 표시하지 않습니다. 변경 후 서버를 재시작해야 반영됩니다.

```yaml
sidebar:
  title: <gold><bold>QUAKE</bold></gold>
  address: <yellow>play.example.com</yellow>
```
